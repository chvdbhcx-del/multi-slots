# Multi Slots

Android-приложение-контейнер: держит много изолированных копий одного приложения (по умолчанию GetContact), в каждой свой залогиненный аккаунт. Переключение в один тап из списка или с ярлыка на рабочем столе, без повторного входа.

## Как это работает

- Внутри открытый движок виртуализации [NewBlackbox](https://github.com/ALEX5402/NewBlackbox) (Apache-2.0). Сборка скачивает его в GitHub Actions.
- Каждый аккаунт живёт в отдельном виртуальном пользователе движка, у каждого свои данные, поэтому вход сохраняется.
- APK GetContact не изменяется и не перепаковывается. Multi Slots запускает в копии то приложение, которое уже установлено на телефоне из Google Play.

## Установка

1. Установите GetContact из Google Play обычным способом.
2. Скачайте последний `MultiSlots-*.apk` из Releases и установите (разрешите установку из неизвестных источников).
3. «Добавить аккаунт», дайте имя (например, номер), откройте копию и войдите по SMS.
4. Повторите для каждого номера. Удерживайте строку: переименовать, ярлык на рабочий стол, обновить, удалить.

## Ограничения

- Для каждого аккаунта нужен свой номер телефона.
- Если GetContact распознает виртуальную среду, он может не запуститься или потребовать повторный вход. Это зависит от сервиса.
- Правила GetContact могут запрещать много аккаунтов на одного человека, аккаунты могут заблокировать.
- Обновления GetContact из Google Play не попадают в копии автоматически: «Обновить приложение в копии» (вход сохраняется).
- Не обновляйте Multi Slots сборкой с другой подписью: Android потребует удалить старую, и все копии сотрутся.
